# daily-meal

## 项目介绍

`daily-meal` 是一个面向日常饮食管理的每日菜谱助手，旨在帮助用户更清晰地掌握每天的用餐安排、食材采购需求与家庭库存情况。系统会根据每日菜谱提醒用户当天是否需要采购食材，并明确需要采购的食材种类和数量，减少临时采购、重复购买或食材浪费的情况。

除了每日采购计划外，项目还会记录剩余食材的数量、存放位置和可用状态，让用户能够快速了解家中还有哪些食材、分别放在哪里，以及是否可以继续用于后续菜谱安排。通过菜谱、采购和库存信息的联动，用户可以更高效地规划一日三餐和家庭食材使用。

在菜谱推荐方面，`daily-meal` 会结合用户的身体情况、健康状况和饮食需求进行动态调整，例如根据体重管理、慢性病控制、营养均衡、忌口或特殊饮食偏好，推荐更适合用户当前状态的每日食谱。项目的设计目标是让每日饮食安排更加健康、清晰、可执行，同时帮助用户建立长期、稳定的饮食管理习惯。

每日菜谱的展示内容会同步维护在 `Schrodinger-CatBug.github.io` 子包的静态页面中，用于通过 GitHub Pages 展示和更新。
