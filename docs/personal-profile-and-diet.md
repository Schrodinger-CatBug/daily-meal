# 个人信息与饮食建议

## 个人基础信息

- 身高：183 cm
- 体重：70 kg
- BMI：20.9
- 职业与生活方式：程序员，日常久坐较多，运动量较少
- 当前状态判断：体重处于正常范围，饮食重点应放在营养均衡、稳定能量、控制久坐带来的代谢压力，以及适当增加优质蛋白和膳食纤维。

> BMI 计算方式：70 / (1.83 * 1.83) ≈ 20.9。该结果仅用于日常饮食参考，不等同于医学诊断。

## 饮食目标

1. 保持当前健康体重，避免因久坐导致脂肪增加。
2. 提高蛋白质摄入质量，支持肌肉维持和基础代谢。
3. 增加蔬菜、全谷物和豆类摄入，改善膳食纤维不足问题。
4. 控制高油、高盐、高糖食物，减少外卖和零食带来的额外热量。
5. 配合轻量运动，让饮食建议更容易长期执行。

## 每日饮食建议

### 早餐

- 推荐搭配：鸡蛋或无糖酸奶 + 全麦面包/燕麦 + 一份水果。
- 目标：提供稳定碳水和蛋白质，避免上午久坐时血糖波动过大。
- 可选食材：鸡蛋、燕麦、全麦面包、牛奶、无糖酸奶、香蕉、苹果、蓝莓。

### 午餐

- 推荐搭配：一份主食 + 一份优质蛋白 + 两份蔬菜。
- 主食建议：米饭、杂粮饭、红薯、玉米、荞麦面。
- 蛋白建议：鸡胸肉、鱼虾、瘦牛肉、豆腐、鸡蛋。
- 蔬菜建议：西兰花、菠菜、番茄、胡萝卜、菌菇、青菜。
- 目标：保证下午工作所需能量，同时避免过油导致犯困。

### 晚餐

- 推荐搭配：清淡蛋白 + 大量蔬菜 + 少量主食。
- 适合方向：低油、低盐、易消化。
- 示例：清蒸鱼 + 炒青菜 + 小份杂粮饭；或豆腐菌菇汤 + 鸡蛋 + 凉拌蔬菜。
- 目标：减少夜间消化负担，避免晚餐过量影响睡眠和体重。

## 加餐建议

- 如下午容易饿，可选择坚果一小把、无糖酸奶、低糖水果或水煮蛋。
- 避免长期用奶茶、甜饮、薯片、饼干作为加餐。

## 久坐程序员注意事项

- 每工作 60-90 分钟起身活动 3-5 分钟。
- 每天至少补充 1500-2000 ml 水，减少含糖饮料。
- 每周安排 3 次轻量运动，例如快走、力量训练、拉伸或骑行。
- 晚餐尽量不要过晚，睡前 2-3 小时避免大量进食。

## 采购建议

- 优质蛋白：鸡蛋、鸡胸肉、鱼虾、豆腐、无糖酸奶。
- 主食与粗粮：燕麦、杂粮米、红薯、玉米、全麦面包。
- 蔬菜：西兰花、菠菜、番茄、胡萝卜、菌菇、青菜。
- 水果：苹果、香蕉、蓝莓、橙子。
- 健康脂肪：坚果、牛油果、橄榄油。

## 一日示例菜单

- 早餐：燕麦牛奶 + 水煮蛋 1-2 个 + 苹果 1 个。
- 午餐：杂粮饭 + 香煎鸡胸肉 + 西兰花和菌菇。
- 加餐：无糖酸奶或坚果一小把。
- 晚餐：清蒸鱼 + 菠菜豆腐汤 + 小份红薯。

## 后续调整方向

如果后续运动量增加，可以适当提高主食和蛋白质摄入；如果体脂增加或体重持续上升，应优先减少高油外卖、甜饮和夜宵，并增加日常步数和力量训练。
